# ASEAM Website

Official-style static website for the Association of Southeast Asian Micronations (ASEAM).

## GitHub Pages

1. Create a new GitHub repository, for example `aseam-website`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide the Pages URL.

## Adding the real logo and flags

The current design uses clean placeholders so the website works immediately. You can later add:
- `ASEAM Flag.png`
- each member state's flag image

and replace the placeholder elements in `index.html` with `<img>` elements.

## Content note

The site follows the information supplied for the ASEAM article, including the six founding members and the seven member states listed as of 13 September 2026.
